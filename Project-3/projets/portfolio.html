Portfolio personnel

Oct. 2026 · Projet personnel

Site statique responsive et accessible, sans framework ni dépendance externe : parcours, projets et contact, avec thèmes clair et sombre.

Voir le code sur GitHub

Contexte

Projet personnel d'octobre 2026, réalisé pour présenter mon parcours et mes projets dans le cadre de ma recherche de stage pour septembre 2027.

Problème

Permettre à un recruteur de comprendre en moins d'une minute qui je suis, de voir des projets concrets et de me contacter ou de télécharger mon CV, sur ordinateur comme sur téléphone.

Solution

Un site statique en HTML, CSS et JavaScript, sans framework ni bibliothèque externe : une page d'accueil, une page par projet, des thèmes clair et sombre.

L'accessibilité est traitée dès le départ : contrastes, navigation au clavier, lien d'évitement, textes alternatifs et respect du réglage « moins de mouvement ».

Les animations sont écrites à la main : réseau de nœuds interactif dans l'en-tête, apparition au défilement, effets de survol. Le site est hébergé sur GitHub Pages.

Technologies

  • HTML
  • CSS
  • JavaScript
  • GitHub Pages

Résultats

  • Un site léger, sans dépendance externe ni suivi.
  • Aucun défilement horizontal sur téléphone, avec une marge de 16 px.
  • Un code source public, disponible sur GitHub.
