Application Symfony conteneurisée

Févr. – mai 2025 · IUT de Metz

Conception et déploiement d'une application Symfony dans une infrastructure Docker : PHP, Nginx, base de données, volumes, automatisation par Makefile et GitLab Container Registry.

Voir le code sur GitHub

Contexte

Projet réalisé à l'IUT de Metz entre février et mai 2025, dans le cadre du BUT Informatique.

Problème

Faire tourner la même application de façon identique sur tous les postes et sur le serveur, sans installer à la main PHP, le serveur web et la base de données à chaque fois.

Solution

Une application Symfony découpée en conteneurs Docker : PHP, serveur web Nginx et base de données SQL, chacun configuré séparément.

Les volumes Docker et la communication entre services sont configurés, et un Makefile automatise les commandes courantes. Les images sont publiées dans le GitLab Container Registry.

L'intégration CI/CD et le déploiement sur un serveur de développement étaient en cours à la fin du projet.

Technologies

  • PHP
  • Symfony
  • Docker
  • Nginx
  • SQL
  • Makefile
  • GitLab

Résultats

  • Environnement reproductible : un même lancement sur n'importe quelle machine.
  • Images versionnées dans le GitLab Container Registry.
  • Première pratique concrète de la conteneurisation, qui nourrit mon orientation vers le cloud.
